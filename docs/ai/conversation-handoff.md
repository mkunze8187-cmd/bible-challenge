# Agon — Cross-Device / New-Conversation Handoff

## Starter prompt (copy into a new ChatGPT conversation)

We are continuing **Agon: The Bible Challenge** design in https://github.com/mkunze8187-cmd/bible-challenge.

Use the connected GitHub repository as the source of truth. Before proposing design, read `AGENTS.md`, `docs/ai/design-principles.md`, `docs/ai/design-workflow.md`, `docs/ai/current-work.md`, and the relevant existing specs, issues, ADRs and code. Search for existing and planned reusable capabilities and compare other games' behaviors before inventing a new one.

**No AI in any shipped or hosted Agon component; all gameplay and content decisions must be deterministic, authored, versioned and reproducible.** Distinguish brainstorming from approved decisions. When I approve changes, commit the relevant spec and GitHub issue updates via normal PR rules. Clearly identify uncommitted decisions.

Today's topic: [game, checkpoint or issue].
