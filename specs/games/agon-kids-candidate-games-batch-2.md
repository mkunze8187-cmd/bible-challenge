# Agon Kids Candidate Games — Batch 2

## Purpose
Candidate additions to Kids Mode (#234–#255). These are backlog ideas, not implementation commitments; any may later be closed `not planned`.

Agon's Kids goal is not merely Bible-themed entertainment. Games should help children **learn Scripture, review/enhance Bible knowledge, and develop habits that encourage them to open and investigate the Bible themselves**. A useful design test is: *if Scripture were removed, would the game lose its core mechanic or learning value?* If not, redesign it.

## Required Scripture loop
Every Kids game implements:
1. **Hear it** — read/narrate the actual passage; show the reference.
2. **Play it** — gameplay represents, recalls, investigates, orders, locates, or applies what the passage actually says.
3. **Say it** — one short memory verse repeated together at the end.
4. **Take it home** — generate a Dig Deeper card (#235): passage, 2–3 parent/teacher questions, memory verse.

### Age profiles
**3–5:** narration-first/pre-reader, picture/large-touch responses, no reading required, timers off by default, no elimination, cooperative/gentle correction, grown-up-held single-device mode.

**6–10:** narration + readable text, physical-Bible lookup encouraged, optional gentle timers/team competition, progressively more direct textual investigation.

## Learning-objective taxonomy extension to #234
Add Admin-editable game/content learning objectives:
- `storyRecall`
- `scriptureMemory`
- `bibleNavigation`
- `textObservation`
- `chronologySequence`
- `speakerContext`
- `context`
- `crossReference`
- `application`

A game may declare several, with one primary objective. Admin/catalog diagnostics should summarize coverage by age group so future content planning can identify over-concentration (for example, many story-recall games but few Bible-navigation games). These are primarily metadata/internal planning facets; they need not become child-facing labels.

# Ages 3–5

## K2-01 Jesus Said…
**Primary:** textObservation / scriptureMemory.

A listening-and-action game based on short, age-appropriate sayings/instructions of Jesus. Narrator first reads the selected passage and reference. During Play, children hear a line or see a picture cue and perform/select the action or meaning tied to the words just heard. This is not generic Simon Says with Bible decoration: every accepted action/cue is authored from the passage and replayable with its verse.

No elimination or tricking preschoolers. Decoys, when used, are gentle picture choices rather than commands designed to make children fail. Host can mark whole-group spoken/physical responses.

**Acceptance:** no reading required; audio replay; passage/reference always available; movement alternative for mobility/accessibility; memory verse closes session; Dig Deeper generated.

## K2-02 Build on the Rock
**Passage:** Matthew 7:24–27. **Primary:** textObservation / application.

Hear Jesus' two-house teaching. Children build one simple house on rock and one on sand using large pieces. Rain/wind arrive; the sand house falls while the rock house stands. Between construction steps, narration repeats the textual contrast: hears Jesus' words **and puts them into practice** versus hears and does not.

The learning target is not merely 'rock is stronger'; Play must explicitly reconnect the visual result to Jesus' stated comparison.

**Acceptance:** gentle/non-frightening animation; no dexterity failure; accessible tap-to-place mode; final prompt asks who the wise builder is like; memory verse + Dig Deeper.

## K2-03 Follow the Star
**Passage:** Matthew 2:1–12. **Primary:** storyRecall / chronologySequence.

After narration, children guide the magi through large illustrated story locations/cards in the order described by the passage, following the star to Jesus. At checkpoints choose an item/person/action actually mentioned in the text. Avoid traditional additions not stated by Matthew (for example, do not require exactly three magi).

**Acceptance:** authored verse link per checkpoint; gentle correction replays relevant line; no false traditional details; picture-first controls; memory verse + Dig Deeper.

## K2-04 Who Did God Make?
**Passage:** Genesis 1:1–2:3. **Primary:** textObservation / storyRecall.

Complement to #236 Let There Be…. Narrate one creation-day excerpt, then show several large pictures. Children select only what the passage says God made/appointed on that day. Replay the relevant line after choices. Later rounds can ask which of two days a picture belongs to.

**Acceptance:** distinct from #236's enactment; no reading required; day/content mapping authored directly from text; no penalty; memory verse + Dig Deeper.

## K2-05 Little Shepherd
**Passages:** starter packs Luke 15:3–7 and Psalm 23 (kept as distinct authored packs). **Primary:** textObservation / scriptureMemory.

Children guide sheep toward the shepherd using simple picture/listening cues drawn from the selected passage. Luke pack emphasizes finding/rejoicing; Psalm pack emphasizes shepherd imagery from the psalm. Do not merge distinct passages as though they are one story.

**Acceptance:** pack-specific wording/reference; audio cues; no sheep can be permanently lost through player error; accessible controls; memory verse + Dig Deeper.

## K2-06 Fill the Basket
**Passage:** Ruth 2. **Primary:** storyRecall / textObservation.

Narrate Ruth gleaning in Boaz's field in short segments. Children collect grain behind the harvesters when prompted by the story, identify Ruth/Boaz/Naomi from pictures, and fill a basket as the narration progresses. The game emphasizes kindness, provision, and what the passage says happened rather than farming dexterity.

**Acceptance:** text-derived actions; simple large targets; no speed requirement; final picture-sequence review; memory verse + Dig Deeper.

## K2-07 Who Said It? — Little Listeners
**Primary:** speakerContext / storyRecall.

After hearing a short story passage, replay a brief quotation/statement from it and show 2–4 large character pictures. Children choose who said it. Then reveal the speaker and replay enough surrounding narration to reinforce context. Starter packs should use unmistakable, age-appropriate speech.

**Acceptance:** quote/speaker/reference authored; avoid isolated quote ambiguity; audio-first; gentle retry; memory verse + Dig Deeper.

## K2-08 Bible Sounds
**Primary:** storyRecall / textObservation.

Narrate a short passage with meaningful sounds/images (storm/waves, rooster, trumpet, sheep, etc.). During Play, children hear/see several cues and identify which belongs to the passage, or tap the matching picture when the narrated textual event occurs. Sounds supplement narration and never replace Scripture.

**Acceptance:** visual equivalent for every audio-only cue; sounds tied to actual textual elements; no requirement to infer speculative sounds; memory verse + Dig Deeper.

# Ages 6–10

## K2-09 Bible Detective
**Primary:** crossReference / bibleNavigation / textObservation.

A Scripture-evidence mystery. Present a question such as 'Who am I?', 'Where did this happen?', or 'What connects these clues?' plus 1–4 Bible references. Teams use physical/digital Bible text to investigate, combine evidence, and submit an answer. Difficulty progresses from one explicit reference to multiple cross-references and less-direct evidence.

Scoring should reward correct evidence, not merely fastest guessing. Host can accept a spoken answer and optionally mark a cited verse.

**Acceptance:** every clue has evidence/reference mapping; accepted aliases; no mystery requiring extra-biblical trivia; post-round evidence board shows how verses combine; memory verse + Dig Deeper.

## K2-10 Prove It!
**Primary:** textObservation / bibleNavigation.

Show a claim about Scripture. Teams decide whether the passage supports it and must locate evidence that proves, corrects, or qualifies it. Claims range from obvious to plausible misconceptions. A response is strongest when paired with a proving verse/reference.

The correction screen must state the accurate claim and show/read the supporting text so a false statement is never left as the remembered takeaway.

**Acceptance:** claim/evidence/reference authored and reviewed; parallel passages supported where appropriate; points for evidence; no gotchas based on translation wording; memory verse + Dig Deeper.

## K2-11 Who Said That? — Context Challenge
**Primary:** speakerContext / context / bibleNavigation.

Older counterpart to Little Listeners. Given a quotation, teams progressively identify speaker, audience, situation, book/reference, and why it was said. Early levels provide the passage; harder levels require finding it. Context questions use surrounding verses, not quote recognition alone.

**Acceptance:** quotation/context mapping; translation-aware answers; post-round surrounding-context view; memory verse + Dig Deeper.

## K2-12 Bible Map Quest
**Primary:** bibleNavigation / textObservation / chronologySequence.

Read a journey passage and use the text to place locations or trace the route on a simplified map. Packs can include Abraham, Exodus, Jesus' ministry journeys, and Paul. Geography should clarify the narrative without claiming certainty where routes are disputed.

**Acceptance:** each route node links to textual evidence; map remains readable on controller/projector; uncertainties labeled; non-drag accessible placement; memory verse + Dig Deeper.

## K2-13 What Does the Text Say?
**Primary:** textObservation / context.

Present three descriptions of a passage/event: one accurately reflects the selected text, another represents a common assumption/traditional embellishment, and another is clearly wrong or textually unsupported. Teams open/read the passage and select what it actually says, then identify the phrase/verse supporting the answer.

The tone is discovery, not 'catching people being wrong.' Traditional details should be described as 'not stated in this passage,' not automatically declared false if Scripture does not address them.

**Acceptance:** careful supported/unsupported distinction; evidence verse; no denominational trap questions; memory verse + Dig Deeper.

## K2-14 Context Clues
**Primary:** context / speakerContext / textObservation.

Start with a recognizable verse or short excerpt. Then expand to verses before/after and ask: Who is speaking? To whom? What just happened? What problem/question is being addressed? How does context change or deepen understanding of the verse?

Difficulty increases context window and inference, not obscure trivia.

**Acceptance:** authored context window/questions; answers directly supportable from passage; full surrounding text available; memory verse + Dig Deeper.

## K2-15 Find the Connection
**Primary:** crossReference / bibleNavigation.

Give two or more passages and have teams discover their connection: quotation, promise/fulfillment, same person/event, repeated image/theme, or explicit textual reference. Players must open/read each passage. Connection type is authored and revealed with an explanation.

**Acceptance:** connection not dependent on unsupported theology; distinguish explicit quotation/reference from thematic similarity; evidence from both passages; memory verse + Dig Deeper.

## K2-16 Book Builder
**Primary:** bibleNavigation.

Build a mental map of Scripture. Players arrange books into canonical order and broad groupings (Law/Pentateuch, History, Poetry/Wisdom, Prophets, Gospels, Acts, Letters, etc., with Admin/content profile able to define labels/order appropriate to the selected canon/tradition). Then a reference appears and teams navigate to its book/group.

Do not make a single denominational canon assumption invisible in the data model.

**Acceptance:** configurable canon/content profile; physical-Bible-friendly mode; ordering and category rounds; no drag-only controls; memory verse + Dig Deeper passage tied to session.

## K2-17 Ask the Passage
**Primary:** textObservation / context.

Reverse the usual quiz. Read a short passage and ask teams to create/select a **good question whose answer can be found in the text**. Younger rounds choose among candidate questions; older rounds type one. Host or authored rubric evaluates whether it is text-answerable. Then another team can answer it from the passage.

This teaches observation and question-asking rather than only retrieving predetermined trivia.

**Acceptance:** choice-mode objective grading; typed mode Host review with rubric; prevent scoring based on theological sophistication; passage remains available; memory verse + Dig Deeper.

## K2-18 Missing from the Story
**Primary:** storyRecall / textObservation / bibleNavigation.

After reading a passage, show a visual/textual set of story elements with one important element absent. Teams identify what is missing and locate the verse containing it. Harder rounds omit less obvious details or require selecting the evidence reference.

**Acceptance:** omissions are textually explicit and meaningful; no trivial spelling/details; evidence reveal; memory verse + Dig Deeper.

## K2-19 Then What?
**Primary:** chronologySequence / bibleNavigation / storyRecall.

Read an event and stop at a natural narrative hinge. Teams predict/select what happened next, then **open/read the next verses to check**. Scoring rewards the textually correct continuation; discussion can compare reasonable predictions with what Scripture actually records.

**Acceptance:** authored stopping points; no misleading truncation; next passage always read/revealed; physical Bible lookup mode; memory verse + Dig Deeper.

## K2-20 Scripture Treasure Hunt
**Primary:** bibleNavigation / crossReference.

A chain of Scripture references. Reading one passage provides the clue needed to identify/find the next book/reference, ultimately revealing a person, theme, phrase, or final answer. Difficulty changes number of hops and directness. The Bible—not external trivia—is the source of every clue.

Support cooperative family/classroom and team-race modes; timers optional so navigation skill is encouraged without punishing newer readers.

**Acceptance:** every chain validated end-to-end; no dead ends; alternate valid references handled; progress persists; final explanation shows the whole chain; memory verse + Dig Deeper.

# Shared implementation requirements
All Batch 2 candidates:
- are candidate/backlog and independently droppable;
- depend on Kids Mode #234 and Dig Deeper/Memory Verse/Story Passport #235;
- implement Hear it → Play it → Say it → Take it home as an enforceable game capability/state flow, not merely documentation;
- display passage references throughout appropriate phases;
- preserve exact distinction between Scripture quotation, narration/paraphrase, game instruction, and interpretation;
- support translation-aware content authoring and avoid relying on one translation's incidental wording unless the content pack explicitly targets it;
- support age-profile accessibility, narration replay, Reduced/Off motion, large touch targets, keyboard alternatives where applicable, and visual equivalents for audio-only information;
- use shared Agon Challenge/Card/Randomizer/Timer/Buzzer/Player Controller/Host Remote/persistence infrastructure where applicable;
- never use betting/wagering mechanics;
- keep normal Kids Mode gentleness/content review;
- generate #235 Dig Deeper output and Memory Verse Wall contribution;
- declare learning-objective metadata and `GameCompetitionCapabilities` as appropriate;
- preserve private answers and authoritative server state;
- include authored-content validation tests and age-profile E2E tests.

## Suggested catalog balance
Use learning-objective metadata to keep the catalog balanced. Ages 3–5 should emphasize listening, story sequence, recognition, and memory. Ages 6–10 should intentionally expand toward Bible navigation, textual observation, context, and cross-reference skills so Agon increasingly teaches children **how to investigate Scripture**, not only facts about Scripture.
